# Sub Zero — Mobile Recovery

Website for Sub Zero, a mobile recovery truck that brings ice baths, sauna, guided stretching and recovery drinks to padel centres, football clubs and gyms in Dubai.

## Run locally

```bash
npm install
npm run dev
```

Opens on http://localhost:5190.

## Publish

```bash
npm run build:docs
```

Builds the site into `docs/`, which GitHub Pages serves from the `main` branch.
